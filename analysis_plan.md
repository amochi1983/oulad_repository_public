# Prespecified OULAD analysis plan

Written 2026-10-05 before data analysis, association tests or predictive performance inspection. The referenced proposal DOCX was not attached; the supplied detailed brief is authoritative.

## Confirmatory analysis
Unit: student × module × presentation. Primary landmark: day 28 (end week 4); observable dates strictly less than 28. Eligibility: known registration date < cutoff and no recorded unregistration < cutoff. Missing registration excludes; unknown withdrawal timing remains unknown, never imputed. Primary outcome is Pass/Distinction success versus Fail/Withdrawn. Primary exposure is distinct active days / (7w), days 0 through 7w-1. Zero recorded positive-click activity is zero engagement. Late registrants remain eligible, with registration lag sensitivity. Pre-course activity is separate.

IMD is residential-area deprivation, not personal income: lower percentile bands are more deprived. Parse lower boundaries, retain original labels; groups 0–30%, 30–70%, 70–100%, Missing. Never assign missing to an ordered group. Verify labels against data and source description before inference.

Fit binomial logit success ~ IMD * active-day proportion + gender + age + education + disability + region + previous attempts + studied credits + module/presentation fixed effects. Student-cluster sandwich covariance. Global interaction Wald test (three coefficients including missing group); separately report known-IMD interaction (two coefficients). Main linear exposure; sensitivity fixed quadratic exposure interacted with IMD, log1p clicks, exclusion of withdrawal/date inconsistencies, non-withdrawn conditional success, and withdrawal outcome. Exploratory tests receive Benjamini–Hochberg adjustment.

Marginal standardisation over observed week-4 baseline covariates, replacing IMD and engagement only. Compare known groups on intersection of their 5th–95th percentile engagement ranges. Prespecified grid 0.25, 0.50, 0.75 retained only inside intersection and with >=100 enrolments per group within ±0.10. Delta-method clustered CIs for average probabilities and paired gaps. These are adjusted observational associations; changing a variable in prediction is not an intervention.

## Prediction and secondary analyses
Windows weeks 1,2,4,6,8,12, recompute eligibility and features separately. Positive class: non-success. 2013 training; 2014 test; remove from training all students present in eligible test. Save assignments and composition; report B/J separately. Future presentation year never encoded. Baseline includes module and B/J type, not presentation identifier. Student-grouped 2013 fitting/tuning validation split, followed by separate student-grouped calibration/threshold split. Modest two-candidate model tuning by validation ROC-AUC, within 2013 only. Primary comparisons use four blocks: A baseline excluding IMD, B including IMD, C B plus cumulative/pre-course engagement, D C plus observed weekly/trend features. Dummy, logistic, random forest, XGBoost, compatible LightGBM. Week 1 has no trends. Select boosting explanation model by week-4/block-D validation AUC only.

Threshold 0.5 reference; F1 threshold learned on calibration subset; exact top 10%/20% rank policies break ties by enrolment ordering. Report ROC-AUC, average precision (PR-AUC label), precision, recall, F1, balanced accuracy, Brier, prevalence, calibration and confusion matrices. Student-cluster bootstrap 200 replicates, fixed seeds, paired feature-block/model differences using identical sampled students; intervals conditional on fitted models, not full retraining uncertainty. Group performance includes FPR/FNR and calibration. No best-week selection. Leave-one-module-out week-4 D evaluation removes shared students, with separate held-out results. Small number of modules limits population transportability.

Secondary assessment submission features join assessment metadata before aggregation, dates < cutoff, non-Exam, non-banked. Score sensitivity explicitly assumes unknown release timing; never treat scores as known at submission. Separate fail conditional on non-withdrawal and subsequent withdrawal models. Four-class exploratory classification if each training class >=100. SHAP and ALE are predictive explanations, not causal evidence; no fabricated interaction values.

## Integrity and outputs
Raw official data immutable, cached downloads with retries, checksum and archive path validation. Audit schemas/missingness/keys/cardinality/dates, preserve zero-click enrolments. Smoke test and meaningful boundary tests precede full execution. Export all tables to CSV/Markdown/workbook and figures to 300-dpi PNG plus SVG, each with underlying CSV. Record failures rather than hiding them. Report all prespecified windows and unsuccessful analyses. No full manuscript and no unsupported novelty claims.
